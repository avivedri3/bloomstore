# נספח ג׳ — תבנית החובה של ספר הפרויקט

`docs/project-book.md` נשאר במבנה הזה. מותר להוסיף פסקה או שורה בטבלה. אסור למחוק פרק, לאחד פרקים, או להחזיר את מבנה הספר הישן (מבוא, תיאור מערכת, ניתוח, עיצוב, מסד, מימוש, ממשק, STP, הדרכה, סיכום).

## לפני הפרקים

1. עמוד שער: בית הספר, מחלקה ומסלול, שם הפרויקט בעברית ובאנגלית, שם המגיש ות״ז, טלפון המגיש, מנחה, טלפון המנחה, כתובת המכללה, תאריך.
2. תוכן עניינים עם קישור לכל פרק ולכל סעיף למטה.
3. הצהרת סטודנט יחיד, ומשפט שהנתונים המוצגים הם להדגמה.

מקור השער: `docs/student-qa-appendix.md`. כתובת המכללה הרשומה בספר: דרך הטייסים 28, תל אביב. טלפונים בפורמט `XXX-XXXXXXX`: מגיש `050-5806570`, מנחה `052-8612379`.
